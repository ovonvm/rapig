# 1. 快速开始

Rapig 2.0 把「网页界面 + 文件服务 + 用户系统 + 后台任务」全部装进一个可执行文件，所以部署只有三步：拿到程序、准备数据目录、打开浏览器登录。

## 1.1 三种部署方式

| 方式 | 适合谁 | 怎么开始 | 默认数据目录 |
|---|---|---|---|
| Linux 安装包（推荐） | 服务器、NAS、长期运行 | 解包后执行 `sudo ./install.sh`，自动注册 systemd 服务 | `/opt/rapig/data` |
| 便携运行 | 临时试用、没有 systemd 的环境 | `./rapig serve`，前台运行 | 程序所在目录下的 `data/` |
| Windows 控制面板 | Windows 10/11 桌面 | 双击 `Rapig.exe`，点「启动服务」 | `%ProgramData%\Rapig\data` |

三种方式运行的是同一个核心程序，功能完全一致，区别只在安装与服务管理方式。

## 1.2 Linux：安装包方式

```bash
tar -xzf rapig-v2.0.0-linux-amd64.tar.gz
cd rapig-v2.0.0-linux-amd64
sha256sum -c SHA256SUMS
sudo ./install.sh
```

安装脚本会：

1. 把程序放到 `/opt/rapig/rapig`，创建受限系统用户 `rapig` 运行它；
2. 生成 `/opt/rapig/rapig.env`（配置文件）并注册 systemd 服务；
3. 启动服务并等待健康检查通过，最后打印访问地址、数据目录和 **管理员初始密码**。

之后执行：

```bash
rapig doctor      # 自检，全绿即可
rapig             # 打开运维菜单（启动/停止/备份/升级等）
```

## 1.3 Windows：控制面板方式

1. 把 `Rapig.exe` 放到一个单独文件夹（不要放在中文或很深的路径下）。
2. 双击运行，在 UAC 弹窗点「是」（程序需要管理员权限写入 `%ProgramData%\Rapig`）。
3. 首次启动会自动创建管理员 `admin`，随机初始密码会显示一次，同时保存在 `%ProgramData%\Rapig\data\bootstrap\initial-admin.txt`。
4. 在首页点「启动服务」，再点「在浏览器打开网盘」。
5. 用 `admin` 和初始密码登录，然后到「设置」修改密码。

## 1.4 便携方式（任意系统）

```bash
chmod +x rapig
./rapig serve
```

浏览器打开 `http://127.0.0.1:50011`。首次启动会打印 `admin` 的初始密码；`Ctrl+C` 优雅退出。数据默认写在程序旁边的 `data/` 目录。

## 1.5 第一次登录

1. 打开 `http://127.0.0.1:50011`。
2. 用户名填 `admin`，密码填安装/首次启动时显示的初始密码。
3. 登录后先到「设置 → 修改密码」改掉初始密码（改密后其它设备上的旧会话会失效）。

> 初始密码只显示一次。忘记时可以：Linux 用 `sudo rapig reset-admin-password`；Windows 用控制面板「高级 → 重置管理员密码」。重置后需要重新登录。

## 1.6 安装后目录速览（Linux）

| 路径 | 内容 |
|---|---|
| `/opt/rapig/rapig` | 程序二进制 |
| `/opt/rapig/rapig.env` | 环境变量配置文件（权限 0600） |
| `/opt/rapig/data/db/rapig.db` | SQLite 数据库（WAL 模式） |
| `/opt/rapig/data/storage/` | 文件内容（按内容哈希存放） |
| `/opt/rapig/data/bootstrap/` | 首次管理员信息（改密后自动删除） |
| `/opt/rapig/backup/` | 备份目录（由备份脚本生成） |

Windows 下对应位置是 `%ProgramData%\Rapig\data`、`%ProgramData%\Rapig\backups`（控制面板「高级 → 打开数据目录/备份目录」可直接打开）。

## 1.7 接下来做什么

- 想让别人也能访问：先读「5. 反向代理与 HTTPS」，不要直接把端口暴露到公网。
- 想在多台设备同步文件：登录后直接上传，「我的文件」就是你的根目录。
- 需要给同事分权限：读「16. 管理后台」的组管理，或先给他们各建一个账号。
- 想定时备份：读「7. 升级、备份与迁移」。

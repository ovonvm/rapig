# Rapig 2.0 使用手册

Rapig 是一个自托管的个人网盘：把一个可执行文件放到自己的电脑或服务器上，打开浏览器就能管理文件、在线播放音视频、创建分享链接，还能让服务器替你下载文件。

Rapig 2.0 是完整重写的版本。它只有一个程序文件，网页界面直接内嵌在程序里，数据保存在本地目录中，不需要数据库服务、Node.js、Python 或额外的 Web 服务器。

这份手册按「从零部署 → 日常使用 → 管理后台 → 排障」的顺序编写，每一节都可以单独阅读；第一次使用建议从「1. 快速开始」看起。

## 你会得到什么

- **一个程序文件**：Linux 下是一个 `rapig` 二进制（可注册为系统服务），Windows 下是一个双击即用的 `Rapig.exe` 控制面板。
- **网页界面**：登录后才能访问，支持多账号，每个账号的文件互相隔离。
- **文件管理**：上传、下载、新建文件夹、改名、移动、复制、删除与回收站、按文件名搜索。
- **在线播放**：音频/视频在页面浮层中播放，支持字幕、歌词、倍速和后台播放；图片与文本可直接预览。
- **分享**：生成带有效期、密码和下载次数上限的分享链接，可同时分享多个文件/文件夹。
- **离线下载**：让服务器从 HTTP 链接下载，或通过 qBittorrent 下载磁力链接与 `.torrent` 种子。
- **组共享空间**：多人加入同一个组，按组内权限共同维护一份文件。
- **管理后台**：用户管理、组管理、审计日志、站点设置、多本地存储。

## 版本与反馈

本手册对应 **Rapig 2.0.0**（2026-10-28 发布）。

- 在线版：<https://ovonvm.github.io/rapig/>
- 手册源码在仓库 `docs/wiki-src/content/`，修改后用生成器重新生成静态页。
- 功能以实际界面为准；如果界面与手册不一致，请以你正在运行的版本为准，并欢迎在仓库 Issues 中反馈。
- 手册随版本更新：升级到新版本后，建议重新浏览「常见问题」与「升级与备份」两篇。

> 提示：Rapig 默认只监听本机（`127.0.0.1:50011`）。要让同一局域网的其它设备访问，请先阅读「5. 反向代理与 HTTPS」或「6. 配置文件说明」中的监听地址说明。

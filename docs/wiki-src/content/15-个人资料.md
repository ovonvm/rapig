# 15. 个人资料与设置

Rapig 2.0 没有单独的「个人资料」页：账号相关的操作集中在**设置页**（`/settings`），入口是右上角账户菜单 →「设置」。

## 15.1 账户菜单

顶栏右上角显示当前用户名，点击展开：

| 项 | 作用 |
|---|---|
| 设置 | 进入 `/settings`（修改密码、注销账号） |
| 登出 | 退出登录，回到登录页 |

## 15.2 修改密码

1. 设置页「修改密码」：填写**当前密码**、**新密码**、**确认新密码**。
2. 规则：新密码至少 8 个字符，不能与当前密码相同，两次输入必须一致。
3. 保存成功后提示「密码已修改，其它设备上的登录已退出」——你当前这台设备也需用新密码重新登录。

忘记密码时无法自助找回（没有邮箱/短信），需要管理员在「用户管理」里重置，见 16.2。

## 15.3 存储用量

- 左侧栏底部显示当前账号的已用空间/配额进度条；配额越大进度越满。
- 分配了配额时，超出后上传会失败并提示空间不足；`0`/不限表示不限制。
- 回收站中的文件**仍计入**已用空间，清理回收站可立即释放。
- 管理员可在「用户管理 → 编辑」中调整单个账号的配额。

## 15.4 注销账号

设置页底部「注销账号」区域说明：提交后账号立即不可用，3 天后永久删除；删除后用户名保留 3 个月。此操作不可撤销，除非在宽限期内用撤销链接或联系管理员恢复。

**操作步骤**

1. 点「申请注销」。
2. 在弹窗中填写**当前密码**，并输入**当前用户名**确认。
3. 点「确认申请注销」。
4. 系统弹出「保存撤销链接」：账号将在某个时间点被永久删除，在此之前可用该链接撤销注销。请**立即复制保存**（弹窗提供复制按钮），关闭后无法再次查看。
5. 提交后你会立即被登出，账号无法再登录。

**撤销注销**：打开保存的撤销链接即可（链接一次性、无需登录），或联系管理员在「用户管理」中恢复账号。

**注意**

- 宽限期内账号及文件仍占用空间；3 天后连同所有文件（含回收站）永久删除，不可恢复。
- 删除后用户名会被保留 3 个月，期间他人无法注册同名账号。
- 管理员账号一般不允许自行注销，请由其他管理员操作。

## 15.5 注册

如果站点开启了注册，登录页有「注册」入口：

| 字段 | 说明 |
|---|---|
| 用户名 | 全站唯一，注册后不可更改 |
| 密码 | 至少 8 个字符 |
| 显示名 | 可选，界面中展示的名字 |

注册成功通常自动登录。站点关闭注册时看不到该入口，需要管理员在「用户管理」里创建账号。

## 15.6 常见问题

| 现象 | 处理 |
|---|---|
| 修改密码后其它设备被登出 | 正常安全行为，用新密码重新登录 |
| 找不到「个人资料」页 | 2.0 合并进「设置」，从账户菜单进入 |
| 忘记密码 | 联系管理员重置，无法自助找回 |
| 误点注销 | 尽快用保存的撤销链接，或请管理员恢复 |
| 注销后用户名还能注册吗 | 保留 3 个月，之后可被注册 |

# 10. 文件管理

「我的文件」是一个按账号隔离的私人空间：每个账号只能看到自己的文件，管理员也不能直接浏览他人的文件内容。

## 10.1 上传文件

| 方式 | 用法 |
|---|---|
| 上传文件 | 工具条「上传文件」→ 选择一个或多个文件 |
| 上传文件夹 | 工具条「上传文件夹」→ 选择整个文件夹，保持原有目录结构 |
| 拖拽 | 把文件/文件夹从资源管理器拖进页面，松手即上传到当前目录 |
| 待上传队列 | 一次选择的文件较多时，先处理 5 个，其余显示在底部「待上传」条中 |

说明：

- 单次选择超过 200 个文件的文件夹上传会被拒绝，请分次上传。
- 同名文件或文件夹不会自动改名：服务端返回「名称冲突」，请改名或换目录后重试。
- 超过 5 个的待上传文件只保存「清单」，刷新页面后点「选择文件继续上传」重新选择即可匹配；超过 7 天未继续会自动清理。
- 上传进度在右上角下载图标旁的「上传」抽屉中查看，可暂停/取消。

## 10.2 新建文件夹

工具条「新建文件夹」→ 输入名称 → 确定。名称规则：不能为空、不能包含 `/`、长度不超过系统上限；同一目录下不能重名。

## 10.3 改名、复制、移动

| 操作 | 入口 | 说明 |
|---|---|---|
| 改名 | 行末「更多」菜单 → 改名 | 只改显示名，不影响内容；同目录不能重名 |
| 复制 | 行末「更多」菜单 → 复制 | 复制到当前目录或目标目录，新名字为「原名 - 副本」 |
| 移动 | 批量条或行末菜单 → 移动 | 在目录树中选择目标目录；可一次移动多项 |

移动/复制到组空间或个人空间之间不支持（跨空间操作会提示错误），组空间说明见 16.3。

## 10.4 删除与回收站

- 删除=移入回收站，默认保留 **7 天**，到期自动彻底删除。
- 删除后 10 秒内可在右下角提示中「撤销」。
- 彻底删除、清空回收站不可恢复，详情见 12. 回收站。
- 组空间内的删除是**永久删除**，不经过回收站，说明见 16.3 组管理。

## 10.5 下载

- 选中文件 → 批量条「下载」或行末「下载」，任务进入「下载」页的浏览器下载队列，可暂停、继续、重试。
- 文件夹不参与批量下载：选择文件夹里的文件请先进入文件夹。
- 同一时间最多并行下载 2 个任务，其余排队。
- 关闭页面不会丢任务：任务记录保存在本机浏览器中（但不保存文件内容）。

## 10.6 搜索

顶部搜索框输入关键词回车，进入搜索结果页：

| 项 | 说明 |
|---|---|
| 匹配方式 | 文件名包含关键词；3 个字符以上走全文索引，更短按前缀/包含匹配 |
| 类型过滤 | 全部 / 文件夹 / 文档 / 图片 / 音频 / 视频 等（按扩展名归类） |
| 排序 | 相关度（默认）或最近修改 |
| 分页 | 每页 50 条，底部「加载更多」 |

搜索结果只能看到自己有权访问的内容；组空间文件出现在结果中时会标注所属组。

## 10.7 配额与用量

- 侧栏底部显示「已用 / 配额」，仅在管理员给你设置了配额时出现；未设配额表示不限。
- 上传前若空间不足会直接报错；可删除文件、清空回收站后再试。
- 回收站中的文件仍占用配额，直到被彻底删除。

## 10.8 直接操作磁盘的注意事项

不要绕过 Rapig 直接移动或删除数据目录里的文件（`data/storage/` 是内容寻址存储，按哈希存放）。手工改动能导致文件丢失或引用错乱；需要备份请用 7. 升级与备份 中的方法。

# 12. 回收站

删除文件默认不会立刻消失，而是先进入回收站，给自己一个反悔的机会。

## 12.1 进入回收站

左侧栏「回收站」进入 `/trash`。列表每行显示：

| 列 | 内容 |
|---|---|
| 名称 | 被删除的文件或文件夹 |
| 原位置 | 删除前所在的目录 |
| 删除时间 | 删除操作发生的时间 |
| 剩余 | 距离自动彻底删除还剩多少天/小时 |

## 12.2 两种删除的区别

| 操作 | 位置 | 结果 |
|---|---|---|
| 删除 | 文件页批量条 / 行末菜单 | 移入回收站，默认保留 7 天 |
| 彻底删除 | 回收站行末「删除」 | 立即从磁盘删除，不可恢复 |
| 清空回收站 | 回收站工具条 | 立即清空全部，不可恢复（需确认） |

> 组空间里的删除是**永久删除**，不会进入回收站，操作前会二次确认。

## 12.3 恢复

1. 在回收站找到条目，点行末「恢复」；勾选多项后可批量恢复。
2. 优先恢复到**原目录**。
3. 如果原目录已被删除，或原目录里已有同名文件，会自动改放到「我的文件」根目录，并在名称后追加 ` (1)`、` (2)` 等序号，保证不覆盖。
4. 恢复后文件回到普通文件列表，「剩余」列不再显示。

## 12.4 保留期与自动清理

- 默认保留 **7 天**：超过保留期的条目由服务端定时清理，列表中的「剩余」会倒计时。
- 保留天数由管理员在「系统设置」中设定，用户界面只显示、不可修改。
- 快到期时请及时恢复；到期后彻底删除不可找回。

## 12.5 与配额的关系

- 回收站里的文件**仍然占用**你的配额与磁盘空间——删除只是改了状态，内容还在。
- 彻底删除（或清空回收站）时才释放配额；如果提示空间不足，先清理回收站。

## 12.6 与账号注销的关系

注销账号（见 15）有 3 天宽限期；宽限期内管理员可以恢复账号。宽限期结束后，账号及其文件（包括回收站内容）会被彻底删除。

## 12.7 常见问题

| 现象 | 原因与处理 |
|---|---|
| 恢复后名字带了 ` (1)` | 原目录已有同名文件，系统自动改名避免覆盖 |
| 找不到刚删除的文件 | 确认是否在「组空间」中删除（组空间直接永久删除，不进回收站） |
| 回收站是空的但空间仍被占用 | 检查是否还有其它文件；回收站只统计当前账号 |
| 想立即释放空间 | 在回收站「彻底删除」或「清空回收站」，不可恢复 |
| 「剩余」显示 0 天 | 即将被清理，请立即恢复 |

## 12.8 数据层面的说明

- 回收站条目在数据库中是「已删除状态」的节点，文件内容仍完整保留，因此恢复很快。
- 彻底删除会删除内容块（当没有其它文件引用它时），这是空间真正释放的时刻。
- 不要直接修改数据库或数据目录来「清理回收站」，请在界面操作；需要整体清理请用管理员备份/维护流程。

# 13. 下载中心

Rapig 有两个下载页面，用途不同：

| 页面 | 含义 | 文件最终在哪 |
|---|---|---|
| 下载（`/downloads`） | 浏览器把文件下载到你自己的电脑 | 你的电脑（浏览器下载目录） |
| 离线下载（`/transfers`） | 服务器替你去网上下载 | 网盘里的某个文件夹 |

## 13.1 浏览器下载（下载页）

**怎么发起**

1. 在文件页勾选文件 → 批量条「下载」；或行末「更多」菜单点「下载」。
2. 也可以把光标放在文件行上按 `空格` 键加入下载队列。
3. 文件夹不参与下载，需要先进入文件夹再选文件。

**任务列表**

| 项 | 说明 |
|---|---|
| 筛选 | 全部 / 进行中 / 已完成 / 失败，标签上显示数量 |
| 显示 | 文件名、大小、进度、状态 |
| 单任务操作 | 暂停、继续、重试（失败时）、取消 |
| 批量操作 | 全部暂停、全部继续、清除已完成 |
| 并发 | 同时最多下载 2 个任务，其余排队 |

**记录说明**

- 下载任务记录保存在浏览器本地，刷新或关闭页面后仍在；但已下载的内容不会保留，重新下载即可。
- 换浏览器/换电脑看不到旧的下载记录（记录不跟随账号同步）。
- 文件保存位置、是否每次询问，由浏览器自身的下载设置决定。

## 13.2 离线下载（服务器下载）

「离线下载」页让服务器去下载，完成后直接存进网盘，适合大文件、慢速源或不想开着电脑等下载的场景。

**创建任务**

1. 在文件页工具条点「离线下载」（保存到当前文件夹），或在「离线下载」页点「新建任务」。
2. 选择链接类型：

| 类型 | 输入 | 说明 |
|---|---|---|
| HTTP 链接 | `https://example.com/file.zip` | 由服务器直接下载；只支持公网 HTTP/HTTPS，私网与回环地址会被拒绝 |
| 磁力链接 | `magnet:?xt=urn:btih:…` | 交给 qBittorrent 下载 |
| 种子文件 | 选择本地 `.torrent` | 交给 qBittorrent 下载；仅支持 `.torrent`，有大小上限 |

3. 可选填「任务名称 / 文件名」，只影响网盘里的显示名称。
4. 提交后任务出现在列表，完成后文件出现在目标文件夹；多文件种子会在该目录下建子目录。

**任务列表**

| 列 | 说明 |
|---|---|
| 名称 | 网盘中的显示名 |
| 来源 | HTTP / 磁力 / 种子 |
| 大小 | 已知时显示，未知显示 `—` |
| 状态 | 排队中 / 下载中 / 已暂停 / 已完成 / 失败 / 已取消 |
| 进度 | 百分比；无法估算时显示动态进度条 |
| 更新时间 | 最近一次状态变化 |
| 操作 | 暂停、继续、删除任务 |

> 「删除」只删除任务记录，**不会删除**已经下载完成的文件。

**关于 qBittorrent**

- 磁力与种子功能依赖 qBittorrent：需要部署方在服务端配置 qB 的 WebUI 地址和账号（环境变量或启动参数），普通用户无法自行配置。
- 未配置 qB 时，创建任务对话框中不会出现「磁力链接」「种子文件」选项，HTTP 直链仍可用。
- Rapig 把任务交给 qB 并在完成后取回文件，**不保种**；下载完成前请不要删除 qB 里的对应任务。
- HTTP 下载受服务器出网策略限制（默认禁止访问内网地址），失败时先确认链接是否公网可直连。

## 13.3 常见问题

| 现象 | 原因与处理 |
|---|---|
| HTTP 任务立刻失败 | 链接不是公网直链、需要登录、或服务器访问不到该站点 |
| 看不到磁力/种子选项 | 服务端未配置 qBittorrent |
| 磁力任务长时间排队 | qB 未连接成功或没有可用 peer，稍后重试或换种子 |
| 下载很慢 | 服务器带宽或源站限速；可暂停后稍后继续 |
| 完成后文件不存在 | 查看任务信息；确认目标文件夹是否已被删除 |
| 提示空间不足 | 清理回收站或删除文件后重试 |

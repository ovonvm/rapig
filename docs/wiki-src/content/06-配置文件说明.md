# 6. 配置文件说明

Rapig 没有 TOML/YAML/JSON 格式的「配置文件」。运行参数只有一个来源：**命令行参数 > 环境变量 > 内置默认值**。安装包在 Linux 上额外生成一个 `rapig.env`，它本质上就是一组环境变量。

## 6.1 配置放在哪

| 平台 / 方式 | 配置位置 | 修改方式 |
|---|---|---|
| Linux 安装包 | `/opt/rapig/rapig.env`（0600，systemd 通过 EnvironmentFile 读取） | `sudo rapig config` 或直接编辑，再 `sudo rapig service restart` |
| Linux 便携 | 无文件；启动参数 / 当前 shell 的环境变量 | `./rapig serve -addr ... -data ...` 或 `export RAPIG_...` |
| Windows 控制面板 | `%ProgramData%\Rapig\gui-config.json`（端口、数据目录、自启等） | 控制面板「高级」页修改后点「保存并重启」 |

## 6.2 常用参数

| 参数（命令行 / 环境变量） | 默认 | 说明 |
|---|---|---|
| `-addr` / `RAPIG_ADDR` | `127.0.0.1:50011` | 监听地址；局域网访问改 `0.0.0.0:50011` |
| `-data` / `RAPIG_DATA_DIR` | 程序旁的 `data/`（安装包为 `/opt/rapig/data`） | 数据库与文件所在目录 |
| `-log-level` / `RAPIG_LOG_LEVEL` | `info` | `debug`/`info`/`warn`/`error` |
| `-profile` / `RAPIG_PROFILE` | `low` | `low` 面向 512 MB 级机器；`high` 面向 4 GB+ |
| `-cookie-secure` / `RAPIG_COOKIE_SECURE` | `auto` | `auto` 按请求是否 HTTPS；HTTPS 反代建议 `always` |
| `-allow-origin` / `RAPIG_ALLOW_ORIGINS` | 空 | 额外允许的浏览器来源，可重复 |
| `-worker` / `RAPIG_WORKER` | `internal` | `external` 时后台任务改由独立的 `rapig worker` 进程执行 |
| `-qb-url` / `RAPIG_QB_URL` | 空 | qBittorrent WebUI 地址，磁力/种子下载需要 |
| `-qb-username` / `RAPIG_QB_USERNAME` | 空 | qBittorrent WebUI 用户名 |
| `-qb-password` / `RAPIG_QB_PASSWORD` | 空 | qBittorrent WebUI 密码（推荐用环境变量） |
| `-allow-private-downloads` / `RAPIG_ALLOW_PRIVATE_DOWNLOADS` | 关 | 允许离线下载访问私网地址（有 SSRF 风险，仅内网测试） |
| `-pprof` / `RAPIG_PPROF` | 关 | 在回环地址暴露 Go pprof，用于诊断 |

`-profile low` 与 `high` 的差别在于数据库连接数、缓存大小、缓存/上传并发等内部参数；普通机器保持默认 `low` 即可，`high` 适合内存充足、并发较大的主机。

## 6.3 rapig.env 示例

```bash
RAPIG_ADDR=127.0.0.1:50011
RAPIG_DATA_DIR=/opt/rapig/data
RAPIG_PROFILE=low
RAPIG_COOKIE_SECURE=auto

# 可选
#RAPIG_WORKER=external
#RAPIG_QB_URL=http://127.0.0.1:8080
#RAPIG_QB_USERNAME=admin
#RAPIG_QB_PASSWORD=change-me
```

查看当前生效的配置：

```bash
sudo rapig config --show
```

交互式修改常用项（监听地址、数据目录、profile、cookie-secure）：

```bash
sudo rapig config
sudo rapig service restart
```

## 6.4 哪些改动需要重启

| 改动 | 是否要重启 |
|---|---|
| 监听地址、端口、数据目录、profile、cookie-secure、worker、qB 连接 | 需要重启服务 |
| 站点设置（站点名、是否允许注册/注销、默认配额） | 保存即生效，不需要重启 |
| 存储策略（管理后台 → 存储） | 保存即生效 |

Linux 重启：`sudo rapig service restart`；Windows：控制面板「保存并重启」。

## 6.5 Windows 控制面板配置

`gui-config.json` 由控制面板维护，一般不需要手工编辑。它保存：监听端口、数据目录、内存 profile、日志级别、Cookie 安全策略、是否开机自启。修改端口或数据目录请走「高级」页，程序会自动重启核心并做健康检查。

## 6.6 命令行与服务的一致性

- 安装方式下，systemd 启动的是 `rapig serve`，它会读取 `rapig.env`；直接运行 `rapig serve` 时**不读** `rapig.env`，请用参数或当前 shell 的环境变量（避免同时启动两个实例争用数据库）。
- Windows 控制面板与命令行核心共用 `%ProgramData%\Rapig`，不要同时运行两者。

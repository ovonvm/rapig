# 17. 常见问题

## 17.1 安装与启动

**网页打不开**

1. 确认服务在跑：`curl http://127.0.0.1:50011/health`（Linux 用 `rapig service status` 或 `systemctl status rapig`）。
2. 默认只监听 `127.0.0.1:50011`，**其它电脑通过局域网打不开是正常的**：请通过反向代理对外，或把监听地址改为 `0.0.0.0:50011`。
3. 端口被占用时改端口（`RAPIG_ADDR` 或启动参数），注意防火墙放行。
4. 看日志：Linux `journalctl -u rapig -n 100`；Windows 控制面板「查看日志」或数据目录下 `logs/rapig.log`。
5. 用 `rapig doctor`（Windows 控制面板「诊断」）检查数据目录、端口、数据库。

**安装后提示没有管理员 / 忘记初始密码**

- Linux：初始密码在安装摘要里，也在 `<data>/bootstrap/initial-admin.txt`（首次改密后删除）。丢了可执行 `sudo rapig reset-admin-password`。
- Windows：首次启动弹窗会显示一次初始密码；忘记可用控制面板「重置密码」。
- 实在无法进入：说明有另一个管理员账号，用它登录后在「用户管理」中重置。

**旧版 1.x 的数据能直接升级到 Rapig 2.0 吗**

不能。Rapig 2.0 是全新重写，数据库结构与数据目录布局都与 1.x 不同。请保留旧版本运行/导出需要的内容，再在新目录部署 2.0。

## 17.2 登录与账号

| 现象 | 原因与处理 |
|---|---|
| 登录后又跳回登录页 | 反向代理下常见：确认用 HTTPS 访问、代理保留原始 Host（含端口）、配置 `RAPIG_COOKIE_SECURE` 为 `auto`/`always` |
| 多次输错密码后无法登录 | 账号有失败锁定策略，等待一段时间再试，或让管理员在「用户管理」重置密码 |
| 注册入口不见了 | 站点关闭了自助注册，请让管理员创建账号 |
| 改完密码被登出 | 正常：修改密码会让其它设备上的会话失效 |
| 想注销账号 | 设置页 →「注销账号」，3 天宽限期；务必保存撤销链接 |

## 17.3 文件与上传

| 提示 | 原因与处理 |
|---|---|
| 空间不足 / quota exceeded | 超出配额：删除文件、清空回收站，或让管理员调大配额 |
| 文件太大 | 超出单文件上限 |
| 同名文件已存在 | 同目录不自动改名：请改名或移动到其它目录 |
| 上传很慢/中断 | 检查网络；大文件建议在网络稳定时上传，失败后重新上传即可 |
| 选中很多文件后只传了 5 个 | 同时排队数有上限，其余进入草稿，稍后自动/手动继续 |

## 17.4 媒体播放

| 现象 | 原因与处理 |
|---|---|
| 视频打不开、只有声音、黑屏 | 浏览器不支持该封装/编码（常见 MKV、HEVC、部分 AV1）。Rapig 不做服务端转码；请下载后用本地播放器，或换成 MP4(H.264)/WebM 等浏览器支持的格式 |
| 字幕不显示 | 侧车字幕需与视频同目录、同名、扩展名为 `.vtt`/`.srt`/`.ass`/`.ssa`（VTT 优先）；非 UTF-8 文本可能乱码 |
| 歌词不显示 | 同目录同名 `.lrc`（UTF-8） |
| 封面不显示 | 同目录同名图片或 `cover.*`/`folder.*`（jpg/png） |
| 换页面后音乐停了 | 全站浮层播放器依赖浏览器允许播放；被拦截时点右上角播放器按钮继续 |
| 播放进度没记住 | 只记忆播放超过 10 秒的内容，且仅保存在当前浏览器 |

## 17.5 分享

| 现象 | 原因与处理 |
|---|---|
| 链接打不开 | 已撤销/已过期/已清理；或访问次数用尽 |
| 提示要密码 | 分享者设置了密码保护，向对方索取 |
| 提示「尝试过于频繁」 | 密码错误次数过多被临时限流，稍后再试 |
| 打包下载失败 | 一次最多打包 5 个文件，分批下载 |
| 分享的文件不能在线预览 | 公开分享页只提供下载，不支持在线预览 |

## 17.6 离线下载 / 磁力链

| 现象 | 原因与处理 |
|---|---|
| 没有「磁力链接/种子文件」选项 | 部署方未配置 qBittorrent（`RAPIG_QB_URL` 等），HTTP 直链仍可用 |
| HTTP 任务立刻失败 | 链接不是公网直链、需要登录、或服务器访问不到该站点 |
| 一直排队/极慢 | qB 未连上或无可用 peer；检查 qB 状态或换源 |
| 完成后找不到文件 | 文件在创建任务时选择的目录；多文件种子会建子目录 |
| 删除任务后文件也没了 | 删除只删任务记录；文件不会自动删除，若消失请查回收站 |

## 17.7 存储与数据

| 问题 | 说明 |
|---|---|
| 数据存在哪 | 默认在可执行文件旁的 `data/`（Windows GUI 版在 `%ProgramData%\\Rapig\\data`） |
| 能直接改磁盘上的文件吗 | 不要。请通过网页/API 操作，否则数据库与文件会不一致 |
| 如何备份 | 见 07：Linux 用安装包自带备份脚本，Windows 用控制面板「备份数据」 |
| 磁盘快满了 | 清空回收站、删除大文件，或增加/切换存储（「存储」页） |
| 回收站清空后空间没变 | 检查是否还有其它文件；回收站内容在彻底删除后才释放 |

## 17.8 系统与运维

| 问题 | 说明 |
|---|---|
| 内存占用多大 | 按低配置档设计运行在 512MB 级；实际取决于并发与预览 |
| Linux 怎么升级 | `sudo rapig upgrade --binary <新二进制>`（自动备份、失败回滚），详见 07 |
| Windows 怎么升级 | 关闭 Rapig，用新的 `Rapig.exe` 覆盖旧文件后重新启动（无命令行升级命令） |
| 怎么卸载 | Linux `sudo rapig uninstall`（会删数据，谨慎）；Windows 在「应用」中卸载 |
| 支持 Docker / 多节点 / 对象存储吗 | 不支持，当前只提供单机单实例部署 |
| 有手机 App / WebDAV 吗 | 没有；手机可直接用浏览器访问 |
| 日志在哪 | Linux `journalctl -u rapig`；Windows 控制面板「查看日志」/ `logs/rapig.log` |

## 17.9 还能问谁

# 3. Windows 部署

Windows 版本的 Rapig 是一个**单文件控制面板**：一个 `Rapig.exe` 同时包含图形界面和网盘服务核心，不需要安装、不需要解压 zip、不需要 .NET 运行时。

## 3.1 系统要求

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 / 11 x64 |
| 权限 | 需要管理员权限（程序已声明，双击时弹 UAC，点「是」） |
| 位置 | 建议单独建一个文件夹存放 `Rapig.exe`，避免中文路径与很深的目录 |
| 网络 | 默认只监听本机 `127.0.0.1:50011` |

## 3.2 第一次运行

1. 把 `Rapig.exe` 放进单独文件夹，双击运行。
2. UAC 弹窗点「是」。
3. 首次启动会自动创建管理员账号 `admin`，并弹出随机初始密码（只显示一次）。
   - 也可以事后查看 `%ProgramData%\Rapig\data\bootstrap\initial-admin.txt`；修改过密码后该文件会被删除。
4. 首页点「启动服务」，等待状态变为运行中。
5. 点「在浏览器打开网盘」，用 `admin` + 初始密码登录。
6. 登录后到「设置」修改密码。

## 3.3 控制面板有什么

| 页面 | 功能 | 说明 |
|---|---|---|
| 首页 | 启动 / 停止 / 重启服务 | 启动后会用健康检查确认核心已就绪 |
| 首页 | 在浏览器打开网盘 | 默认浏览器打开 `http://127.0.0.1:50011` |
| 首页 | 运行日志 | 显示最近的服务输出，便于排错 |
| 首页 | 查看 / 复制初始密码 | 读取初始管理员信息文件，改密后不可再读 |
| 高级 | 端口与配置 | 修改监听端口（1–65535）等，保存并重启生效 |
| 高级 | 运行自检 doctor | 检查数据目录、数据库、磁盘空间等 |
| 高级 | 备份数据（zip） | 打包数据目录到 `%ProgramData%\Rapig\backups` |
| 高级 | 打开数据目录 / 备份目录 | 在资源管理器中直接打开 |
| 高级 | 更改数据目录 | 只能选择空目录；停止服务后迁移 |
| 高级 | 重置管理员密码 | 忘记密码时使用，重置后需要重新登录 |
| 高级 | 登录 Windows 时自动启动（最小化） | 写入当前用户的启动项，无需计划任务 |

## 3.4 数据放在哪

| 路径 | 内容 |
|---|---|
| `%ProgramData%\Rapig\data\db\rapig.db` | 数据库（SQLite） |
| `%ProgramData%\Rapig\data\storage\` | 文件内容 |
| `%ProgramData%\Rapig\data\bootstrap\` | 初始管理员信息（改密后删除） |
| `%ProgramData%\Rapig\backups\` | 备份 zip |
| `%ProgramData%\Rapig\core\rapig-core.exe` | 首次启动时释放的服务核心 |
| `%ProgramData%\Rapig\gui-config.json` | 控制面板配置（端口、数据目录、自启等） |

备份、迁移、重装都以 `%ProgramData%\Rapig` 为准；卸载前请确认是否需要保留这里的数据。

## 3.5 让局域网里的其它设备访问

控制面板默认只监听本机，这是最安全的默认值。如需局域网访问：

1. 高级页把端口保持不变，或改成你想要的端口。
2. 在防火墙中放行该端口，并把监听地址改为 `0.0.0.0`（通过命令行参数）或在本机放一个反向代理。
3. 其它设备访问 `http://<这台电脑的局域网 IP>:50011`。

> 注意：局域网明文访问意味着同网段的人可能看到传输内容。正式使用建议按「5. 反向代理与 HTTPS」在反向代理上配置 HTTPS。

## 3.6 升级

1. 首页点「停止服务」。
2. 用新的 `Rapig.exe` 覆盖旧文件（数据在 `%ProgramData%\Rapig`，不受影响）。
3. 重新双击运行，点「启动服务」。

升级前建议先在「高级 → 备份数据」做一次 zip 备份。Rapig 的数据库迁移在启动时自动执行，不需要手工操作。

## 3.7 卸载

1. 首页「停止服务」。
2. 关闭控制面板。
3. 删除 `Rapig.exe` 所在文件夹。
4. 如需彻底清除：删除 `%ProgramData%\Rapig`（**会删除所有数据，不可恢复**）。
5. 若开过开机自启，在「任务管理器 → 启动」或「设置 → 应用 → 启动」中删除 `Rapig` 项。

## 3.8 只想用命令行核心

控制面板本质是给 `%ProgramData%\Rapig\core\rapig-core.exe` 套了一层界面。也可以直接命令行运行：

```powershell
& "$env:ProgramData\Rapig\core\rapig-core.exe" serve
```

此时数据仍使用 `%ProgramData%\Rapig`，与图形界面共用，不要同时启动两份。

8. 登录与账号

Rapig 默认是一个多用户网盘：管理员创建账号，或由站点开放自助注册。每个账号的「我的文件」互相隔离。

8.1 登录

  1. 打开 Rapig 地址（默认 http://127.0.0.1:50011），进入登录页。
  2. 「用户名 / 邮箱 / 手机号」填任意一个，再填密码。
  3. 点登录。成功后进入「我的文件」。

登录失败时页面只提示「用户名或密码错误」，不会说明账号是否存在。连续输错 5 次会临时锁定该账号，页面会显示倒计时；等待结束或联系管理员重置密码。

8.2 第一次登录（管理员）

  • 安装或首次启动时程序自动创建管理员 admin。
  • 初始密码只显示一次：Linux 安装摘要 / 首次前台启动的控制台输出；Windows 控制面板弹窗；同时写入数据目录的 bootstrap/initial-admin.txt。
  • 首次登录后请立刻到「设置 → 修改密码」。修改后初始密码文件会被删除，其它设备上的旧会话也会失效。
  • 忘记密码：Linux sudo rapig reset-admin-password；Windows 控制面板「高级 → 重置管理员密码」。重置会撤销该用户全部会话。

8.3 注册

注册默认关闭。管理员可在「系统设置 → 允许注册」中打开（只有 root 管理员能改）。

开启后，登录页会出现「注册账号」入口。注册表单要求：

字段说明
用户名（选填）2–32 个字符，只能包含字母、数字、.、_、-
邮箱（选填）格式校验，不发送验证邮件
手机号（选填）格式校验，不发送短信
密码 / 确认密码8–128 个字符（按字节计）

用户名、邮箱、手机号至少填一项即可注册；只填邮箱或手机号时，系统会自动分配一个 u 开头的用户名。注册成功后不会自动登录，请回到登录页登录。同一 IP 的注册请求有频率限制。

8.4 角色与权限

角色说明
管理员可进入后台：用户管理、组管理、审计日志、系统设置、存储
成员只能使用自己的文件、组空间、分享、下载等

第一个管理员是 root 管理员（主要管理员）：只有 root 能修改「允许注册」「允许注销」两个开关；root 不能被禁用、降级或删除。管理员对别人的文件没有特殊读取权限，越权访问统一返回 404 或拒绝。

8.5 账号状态

状态含义
正常可正常登录使用
已禁用管理员停用了账号，无法登录；数据保留
注销中已申请注销，等待 3 天宽限期结束
临时锁定连续登录失败被临时锁定，到期自动解除

被停用的账号需要管理员在「用户管理」中「启用」后才能登录。

8.6 修改密码

「账户菜单 → 设置 → 修改密码」：输入当前密码、新密码、确认新密码。新密码至少 8 个字符。修改成功后，除当前设备外的其它登录会话会被强制退出。

8.7 注销账号

「设置 → 注销账号」可自助注销：

  1. 输入当前密码，并输入自己的用户名做二次确认。
  2. 提交后账号进入「注销中」状态，宽限期 3 天。
  3. 页面会显示一次性「撤销注销」链接，请立即保存；链接关闭后无法再次查看。
  4. 宽限期内账号不能登录，已创建的分享会失效；可以联系管理员恢复，或用撤销链接撤销。
  5. 3 天后系统自动删除账号及其文件，不可恢复。
  6. 注销后用户名会保留约 3 个月，期间不能被重新注册。

管理员账号不能自助注销（root 管理员尤其如此）。如需处理管理员账号，请用另一个管理员在「用户管理」中禁用或清除。清除操作会立即删除数据，请谨慎。

8.8 安全建议

  • 每个使用者单独一个账号，不要共用管理员。
  • 公网部署必须配 HTTPS，并改掉初始密码。
  • 定期检查「用户管理」里的异常账号与「审计日志」中的登录失败记录。
  • 账号被停用/注销后，其分享链接会失效；如怀疑泄露，直接撤销对应分享。

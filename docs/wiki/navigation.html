9. 导航与界面

登录后的所有功能都通过一个网页界面完成，不需要另装客户端。

9.1 顶部栏

元素位置作用
站点标志左点击回到「我的文件」根目录
搜索框中按文件名搜索；回车进入搜索结果页（见 10.6）
下载中心图标右打开浏览器下载面板；有进行中的任务时显示数字角标
账户菜单右「设置」（修改密码、注销账号）与「登出」

9.2 左侧栏

左侧栏按登录身份显示不同入口，当前页面会高亮。

所有用户

入口页面说明
我的文件/files个人根目录；文件、文件夹都在这里
组空间/groups/<id>你加入的每个组显示为一条，组后带「管理员」标记表示你是组长
分享/shares你创建的分享链接列表
下载/downloads浏览器本机下载队列（跨页面保留）
离线下载/transfers由服务器执行的 HTTP / 磁力 / 种子下载任务
回收站/trash已删除的文件；有内容时显示数量角标
设置/settings修改密码、注销账号

管理员额外显示

入口页面说明
用户管理/admin/users创建、禁用、重置密码、永久删除账号
组管理/admin/groups建组、维护成员与组员权限（被委派建组权限的用户只看到「我的组」）
审计日志/admin/audit按操作者 / 动作 / 时间查询
系统设置/admin/settings站点名称、注册开关、默认配额等
存储/admin/storage多本地存储根的查看与维护

侧栏底部显示存储用量条：只有账号设置了配额时才出现，格式是「已用 / 配额」。

9.3 文件页的结构

文件页从上到下依次是：

  1. 面包屑：显示当前位置，点击任意一级可跳回；根目录显示为「我的文件」。
  2. 工具条：新建文件夹、上传文件、上传文件夹、离线下载，以及右侧的「列表 / 网格」切换。
  3. 文件区：列表（适合看大小与时间）或网格（适合看缩略图与封面）。
  4. 批量条：勾选任意文件/文件夹后从底部出现，包含全选、下载、分享、移动、复制、删除。

9.4 选择文件

操作效果
单击行首复选框或文件名前的选择框选中一项
Shift + 点击选中连续的区间
Ctrl（macOS 为 ⌘）+ 点击加选 / 取消单项
在空白处按住拖动框选
列表头复选框全选当前页

9.5 视图偏好

「列表 / 网格」的选择记在本机浏览器里，下次登录仍保持；不同账号之间互不影响。

9.6 手机与窄屏

窗口宽度小于约 860 像素时，左侧栏会隐藏。此时通过顶部栏的搜索框、下载中心与账户菜单进入各页面；桌面端请用宽屏以获得完整导航。

9.7 快捷键与小技巧

  • 空格：把当前选中的文件加入下载队列（在输入框或对话框中不生效）。
  • Esc：关闭对话框、顶部搜索和下载面板。播放浮层用右上角按钮「收起」（音频继续播放）或「关闭并停止」。
  • 双击文件或文件夹：打开（进入目录 / 播放或预览）。
  • 把文件或文件夹拖到页面任意位置：直接上传到当前目录。
  • 分组标题（如「我的文件」「组空间」）不可点击，只用于分区。

9.8 页面打不开时

  • 刷新页面后仍在原页面（地址里带目录 id），说明地址可直接收藏。
  • 若提示登录失效，会跳回登录页；重新登录即可。
  • 权限相关页面（例如组空间）打不开时，通常是没有加入该组或链接已过期，见 17. 常见问题。

16. 管理后台

管理后台面向管理员，用来管理用户、组、审计日志、站点设置与存储。普通用户看不到这些入口。

16.1 怎么进入

左侧栏底部「管理」分组：

入口页面谁能看到
用户管理/admin/users管理员
组管理/admin/groups管理员；被授予「允许建组」的用户看到的是「我的组」
审计日志/admin/audit管理员
系统设置/admin/settings管理员（其中部分开关仅 root 管理员可改）
存储/admin/storage管理员

直接访问这些地址也要求管理员登录；普通用户会被拒绝。

16.2 用户管理

页面顶部有搜索框（按用户名）和「创建用户」按钮，列表右侧可「加载更多」。

元素说明
列表列用户、角色、状态、配额、创建时间
编辑修改显示名、角色、允许建组、配额等
禁用 / 启用禁用后该用户立即无法登录；启用后恢复
重置密码生成一次性密码，只显示一次，请当场抄给用户
筛选注销状态可切换到「注销中」查看宽限期内的账号

创建用户：填写用户名、显示名、角色、配额；初始密码可以留空，留空时系统自动生成一次性密码，创建后只展示一次。

注销中的账号：额外显示「恢复账号」「立即永久删除」两个操作。

  • 恢复账号：撤销注销，账号立即可用（宽限期内有效）。
  • 立即永久删除：跳过 3 天宽限期，立刻删除账号及其全部文件，不可恢复。
  • root 管理员不能被删除；任何管理员都不能对自己做禁用/重置/删除/恢复操作。

16.3 组管理

组 = 共享空间。管理员可新建组、管理成员、设置组员权限、删除组。

操作说明
新建组填写组名称（最多 64 字符），设置默认组员权限
成员按用户名搜索或填用户 ID 添加；可设「管理员（manager）」或「成员（member）」，设置其六项权限
设置修改组名称、默认组员权限
删除组删除组本身；组内文件的处理见下方注意事项

组员六项权限（默认只读，可按组或按成员调整）：查看、上传、下载、新建文件夹、重命名/移动、删除。组管理员始终拥有全部权限。

删除组会移除共享关系，操作前请确认组内文件是否需要保留（需要时先各自下载或复制）。

16.4 审计日志

记录管理操作与关键业务动作，用于追溯「谁在什么时候做了什么」。

  • 筛选条件：操作者（用户名）、动作、开始时间、结束时间；「查询」应用，「重置」清空条件。
  • 列表列：时间、操作者、动作、对象、结果、IP、请求 ID。
  • 分页显示，底部可加载更多。
  • 保留天数在「系统设置 → 保留策略」中只读展示。

普通用户看不到审计日志；管理员的操作同样会被记录。

16.5 系统设置

字段说明修改权限
站点名称显示在分享页与浏览器标题中，最多 64 个字符root 管理员
允许注册关闭时只能由管理员创建账号仅 root 管理员
允许用户注销账号关闭后用户无法自助注销（注销有 3 天宽限期）仅 root 管理员
新用户默认配额（GB）十进制 GB，0 表示不限root 管理员
保留策略审计日志保留天数、回收站保留天数，只读展示部署时决定

修改后点「保存」，页面会提示未保存状态；「还原」可放弃修改。注意：非 root 管理员打开页面时，普通项可改，root 专属项为禁用状态。

16.6 存储

管理「数据落在哪个磁盘目录」。

列说明
名称 / 根路径存储策略名与磁盘路径
状态启用 / 停用
默认新文件夹默认使用的存储
已用该存储已占用的空间
节点 / 文件引用该存储的节点数与文件数
操作编辑、停用/启用、删除

新建存储：填写名称与根路径；「设为默认」要求该存储已存在且启用。根路径应位于 Rapig 数据目录范围内，便于备份与权限管理。

删除限制：仍有节点/文件使用的存储不能删除；要删除默认存储，需先把其它存储设为默认。

16.7 与部署相关的管理项

以下内容不在网页后台里改，需要部署方在服务器上操作（详见 06 与 07）：

项方式
qBittorrent 连接环境变量 RAPIG_QB_URL / RAPIG_QB_USERNAME / RAPIG_QB_PASSWORD（或启动参数），改后重启
监听地址、数据目录、profile配置文件 / 环境变量 / 启动参数
备份与恢复管理脚本 backup.sh / restore.sh（Linux 安装包自带）
日志服务日志（Linux journalctl / Windows 日志文件）

16.8 常见问题

现象处理
看不到管理入口当前账号不是管理员
root 专属开关是灰的需用 root 管理员账号登录（初始创建的那个管理员）
组管理标题是「我的组」当前账号是被委派的建组用户，只能看到自己的组
无法删除存储该存储仍被节点使用，或它是默认存储
忘记管理员密码用 rapig reset-admin-password（Linux）或控制面板重置（Windows），见 07
